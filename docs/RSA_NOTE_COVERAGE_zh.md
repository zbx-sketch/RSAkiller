# RSA 笔记兼容性与回归覆盖

本页记录“智能粘贴”模式针对随附 RSA 笔记建立的可复现回归范围。测试夹具中的答案文本已统一替换为 `[REDACTED_FLAG]`；断言只保存预期明文的 SHA-256，因此测试必须从 RSA 参数实际恢复明文并通过重新加密或因子乘积检查。

## 覆盖矩阵

| 笔记案例 | 自动识别与求解路径 | 关键验证 |
|---|---|---|
| RSA4 | 受限数字字母表推断五进制 → 三组 Håstad 广播攻击 | CRT 后为精确立方；三组重新加密一致 |
| RSA5 | 批量模数两两 GCD → 共享素数恢复私钥 | 非平凡 GCD、`p*q=n`、重新加密一致 |
| RSA9 | Python 2 `L` 后缀清理 → `e=3` 精确开根 → 明文 MD5 指令 | 精确立方与重新加密一致 |
| RSAROLL | `{n,e}` 推断 → 小模数分解 → 重复逐字符密文按原顺序拼接 | 因子乘积及每个字符重新加密一致 |
| RSA 不给 e | 已知 `p/q/dp/dq`，直接 CRT 解密 | 两个 CRT 剩余分别一致 |
| RSA dp 泄漏 | `gcd(a^(e*dp)-a,n)` 恢复因子 | 因子乘积及重新加密一致 |
| RSA 共享素数 | 两组 `n/c` 批量 GCD | 非平凡 GCD、因子乘积、重新加密一致 |
| RSA 标准共模 | Bézout 系数与带符号模幂 | 两组密文重新加密一致 |
| RSA 共模非互素指数 | 先恢复 `m^g`，再精确开 `g` 次方根 | 两组密文重新加密一致 |
| RSA 已知 p/q 解 m | 重建 `lambda(n)` 与 `d`，按题面模板输出整数明文 | 因子乘积及重新加密一致 |
| babyRSA | 相邻素数 Fermat → 解密两组中间量 → 立方和/韦达恢复两半 | 两次 RSA、整除关系、判别式及立方和均验证 |
| childRSA | 根据 `sieve_base` 构造识别光滑 `p-1` → Pollard p−1 | 非平凡 GCD、因子乘积及重新加密一致 |
| SameMod | 裸 `{n,e}` 公钥对 → 共模攻击 → 十进制 ASCII 串接解码 | 两组密文重新加密一致 |

## 自动解析范围

- 十进制、`0x`、`0b`、`0o` 与 Python 2 `L` 后缀；
- `n/e/c/p/q/d/dp/dq`、带数字后缀的多组变量、重复的 `n =` / `c =` 块；
- 独立行 `{n,e}` 或 `(n,e)` 公钥，以及逐行密文；
- 明文 UTF-8、逐字符拼接、十进制 ASCII 串接、题面中的 MD5 指令及平台前缀候选；
- 题目源码只作为文本读取，不调用 `eval`、`exec` 或解释器执行。

## 运行验证

```bash
# 笔记兼容性与解析器安全测试
python -m pytest -q tests/test_ctf_solver.py

# Web API、任务取消、输出与智能粘贴集成测试
python -m pytest -q tests/test_web.py

# 全量回归
python -m pytest -q
```

智能模式只负责有明确、可验证数学关系的路径。若题目需要自定义 Sage 多项式、未知消息结构、特殊编码或未被识别的生成逻辑，请切换“手动高级”并选择对应攻击模块。未得到闭环结果时，界面会明确报告失败，不把仅看似可读的字符串当成成功。
